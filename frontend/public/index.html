attestation prototype

defs are templates. ins are live work. overlapping tasks share one task_ins row.

how to test dedup

  1. create two task defs (e.g. DUA, HIPAA)
  2. create two workflow defs that share one of those tasks
  3. create a user
  4. on the user page, assign both workflows
  5. shared task appears once under task_ins, linked from both workflow_ins
  6. complete the shared task — both workflows see it done
  7. archive a workflow or make a new version (old instances stay pinned)
