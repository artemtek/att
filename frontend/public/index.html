how to test

  2. create two workflow defs that share a task, e.g. researcher (whitelist) and PI (whitelist), both including DUA
  3. create a user; create a reviewer with legal_rep_institutional_data_reviewer and a whitelister
  4. assign both workflows — shared task_ins id appears once
  5. submit the shared task once; approve on certifications as the reviewer
  6. both workflows move; whitelist on whitelisting
  7. user_auth_roles gains the granted role
